# Fixtures docx4j

Estos documentos binarios se usan exclusivamente como fixtures de pruebas para `report-service`. Fueron tomados de los ejemplos publicos del proyecto Apache docx4j en `C:\ELIMINAR\docx4j` y no representan plantillas productivas.

Antes de redistribuirlos fuera del repositorio de pruebas, conserva la licencia y los avisos del proyecto original. No agregues datos personales, tokens ni secretos a estos documentos.

Fixtures incluidos:

- `invoice-opendope.docx` y `invoice-original-data.xml`: OpenDoPE, repeticiones y condiciones.
- `MERGEFIELD.docx`: campos de combinacion.
- `picture.docx` y `picture-data.xml`: imagen y relaciones de medios.
- `Headers.docx`: historias de encabezado y pie.
- `toc.docx`: TOC y bookmarks.
- `clustered-column.docx`: chart con workbook XLSX embebido.
